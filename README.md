E-Commerce Website
A web application that allows users to browse, add to cart, and purchase products online with a full admin panel for managing inventory and orders.
Features

Register and log in securely as a customer or admin
Browse products by category and subcategory
Add products to cart or save them to a wishlist
Place orders and track order status in real time
Admin panel to manage products, users, categories, and orders

Tech Stack

Frontend: HTML, CSS, Bootstrap, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (via XAMPP)

How It Works

User registers or logs in to their account
User browses available products and adds them to the cart or wishlist
User proceeds to checkout and places an order
Order details are saved to the database and shown in order history
Admin manages products, categories, and orders through a central dashboard

Project Status
Frontend code completed.
Backend (PHP + MySQL) integration in progress.
